# Infrastructure-management-dashboard
This is a business intelligence dashboard for company It covers FY 2025, with 450 billing records. The banner on both screenshots says "Frontend Preview Only", so the backend isn't running and the numbers may be sample data.

INFRASTRUCTURE BUSINESS INTELLIGENCE DASHBOARD - MVP
=====================================================
Windows-ready local Flask + SQLite MVP for Pritam Ganjewar Infrastructure Pvt. Ltd.

QUICK START
1. Install Python 3.10+.
2. Extract the ZIP.
3. Double-click run.bat.
4. Open http://127.0.0.1:5000
5. Login: admin / admin123

Features: dashboard KPIs, projects, revenue, expenses, customers, products/services,
reports, CSV/XLSX import and export, role-based users, responsive UI, SQLite.

Change the default password before real-world use.
